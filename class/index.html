Repository Anatomy & Chronological 4-Phase Discipline

GEMINI.md — Project Constitution

Always loaded into agent context. Defines the 4-phase research order (Data → Modeling → Inference → Analytics), forbids train/validation/test leakage, forbids hardcoding physical thresholds outside .env, and requires written plans before major code or manuscript edits.

Dataset Hygiene Golden Rule: Fit scalers, imputers, and hyperparameter trials strictly on train; rank candidates on validation; touch test exactly once after the entire architecture is frozen.

LLMs frequently blend author names, years, and DOIs when asked to cite from memory. Under .agents/rules/literature.md, agents must verify every reference live with verify_doi.py (Crossref API → APA 7th) before writing a single in-text citation.

Module 6 • Reproducible Audit Trails

Documentation Synchronization & Verbose Git Telemetry

Scientific code evolves rapidly. Running /update-documentation and /commit ensures notebook summaries, compiled code snapshots, package lists, and manuscript diff guides stay synchronized at every milestone.

/update-documentation

Runs audit_docs_sync.py --compile-nbs to verify requirements.txt == README.md, check every notebook has a docs/summary/*_summary.txt, and pass strict manuscript QA.

/commit (v0001 - <summary>)

Runs pre-commit manuscript QA, writes a verbose multi-bullet commit, then regenerates log_github_lastrun.csv and .docx via sync_telemetry.py as v0002.
